Pipe:
-----------------
transformer -> transforming data before the data gets "bound" in the UI

@Pipe({ name:'uppercase'})
export class UpperCasePipe implements PipeTransform{
	transform(value:string, ...args:any[]):string{
		return value.toLocaleUpperCase();
	}
}

import the class in the "imports" array in a component metadata
use in the template like the following:

{{record.name|uppercase}}

-> new UpperCasePipe().transform(record.name)

register service provider:
---------------------------------
service provider: which provides metadata of a service to Angular's DI framework
type: Provider
	a. ClassProvider: provide and useClass
	b. ValueProvider: provide and useValue
	c. ExistingProvider: provide and useExisting
	d. FactoryProvider: provide and useFactory

create provider:
--------------------
1. when the token is none other than the class itself (default provider)

const TOKEN  = PersonService

defaukt provider (class provider)
{
	provide: TOKEN
	useClass: PersonService/ useValue: new PersonService/ useFactory: ()=>{ return new PersonService()}
}

value provider:
{
	provide: TOKEN
	useValue: new PersonService
}

factory pprovider:
{
	provide: TOKEN
	useFactory: ()=>{ return new PersonService()}
}



2. when the token is a string (custom provider)

const TOKEN  = 'TOKEN'

{
	provide: TOKEN,
	useClass: PersonService
}

3. when the token is an object of InjectionToken type (custom provider)

const TOKEN = new InjectionToken<PersonService>('TOKEN')

{
	provide: TOKEN
	useClass: PersonService
}
